# Livraria Client-Server

Projeto desenvolvido utilizando arquitetura Cliente-Servidor.

## Tecnologias

### Cliente
- HTML
- CSS
- JavaScript

### Servidor
- Python
- Flask
- SQLite

## Funcionalidades

- Salvar livros
- Pesquisar livros
- Remover livros

## Como executar

### Servidor

```bash
cd servidor

pip install -r requirements.txt

python app.py
